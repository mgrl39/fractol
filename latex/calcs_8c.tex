\doxysubsection{Detailed Description}
Core calculations for fractal rendering. 

This file contains the functions responsible for performing the core calculations required to render fractals. It handles\+:
\begin{DoxyItemize}
\item Scaling and positioning the fractal within the rendering window.
\item Precomputing the coordinates ffor each pixel to optimize rendering performance.
\item Rendering the fractal by delegating to specific algorithms (Julia or Mandelbrot).
\item Mapping iteration counts to colors for visually representing fractal complexity.

For non-\/technical users\+:
\begin{DoxyItemize}
\item This file performs the "{}math magic"{} that powers the fractal visuals, calculating where and howw the fractal is drawn and colored on the screen. 
\end{DoxyItemize}
\end{DoxyItemize}
