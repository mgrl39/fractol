{\ttfamily ft\+\_\+strcmp} compara dos cadenas de texto ({\ttfamily s1} y {\ttfamily s2}) carácter por carácter. Si ambas cadenas son idénticas, devuelve {\ttfamily 0}. Si no, devuelve la diferencia numérica entre los valores ASCII del primer par de caracteres diferentes.\hypertarget{md__2home_2dev_2frfr_2auxiliary__explained_autotoc_md4}{}\doxysubsection{\texorpdfstring{Parámetros}{Parámetros}}\label{md__2home_2dev_2frfr_2auxiliary__explained_autotoc_md4}

\begin{DoxyItemize}
\item {\ttfamily const char \texorpdfstring{$\ast$}{*}s1}\+: Puntero a la primera cadena de texto que se desea comparar.
\item {\ttfamily const char \texorpdfstring{$\ast$}{*}s2}\+: Puntero a la segunda cadena de texto que se desea comparar.
\end{DoxyItemize}\hypertarget{md__2home_2dev_2frfr_2auxiliary__explained_autotoc_md5}{}\doxysubsection{\texorpdfstring{Retorno}{Retorno}}\label{md__2home_2dev_2frfr_2auxiliary__explained_autotoc_md5}

\begin{DoxyItemize}
\item Devuelve {\ttfamily 0} si las cadenas son iguales.
\item Devuelve un valor positivo si {\ttfamily s1} es mayor que {\ttfamily s2} (el primer carácter diferente en {\ttfamily s1} tiene un valor ASCII mayor que en {\ttfamily s2}).
\item Devuelve un valor negativo si {\ttfamily s1} es menor que {\ttfamily s2} (el primer carácter diferente en {\ttfamily s1} tiene un valor ASCII menor que en {\ttfamily s2}).
\end{DoxyItemize}\hypertarget{md__2home_2dev_2frfr_2auxiliary__explained_autotoc_md6}{}\doxysubsection{\texorpdfstring{Detalles del funcionamiento}{Detalles del funcionamiento}}\label{md__2home_2dev_2frfr_2auxiliary__explained_autotoc_md6}

\begin{DoxyEnumerate}
\item Iteración carácter por carácter\+:
\begin{DoxyItemize}
\item Compara los caracteres correspondientes de {\ttfamily s1} y {\ttfamily s2} hasta que encuentra una diferencia o llega al final de una de las cadenas.
\end{DoxyItemize}
\item Verificación de igualdad\+:
\begin{DoxyItemize}
\item Si los caracteres son iguales, sigue comparando.
\item Si encuentra un carácter diferente, calcula y devuelve la diferencia entre sus valores ASCII.
\end{DoxyItemize}
\item Cadena más corta\+:
\begin{DoxyItemize}
\item Si una cadena termina antes que la otra, la función considera que la más corta es "{}menor"{}.
\end{DoxyItemize}

{\ttfamily fr\+\_\+putstr\+\_\+fd} escribe una cadena de texto ({\ttfamily s}) en un descriptor de archivo ({\ttfamily fd}). \item {\ttfamily int fd}\+: Descriptor de archivo donde se escribe la cadena\+:
\begin{DoxyItemize}
\item {\ttfamily 1} para salida estándar ({\ttfamily stdout}).
\item {\ttfamily 2} para salida de error ({\ttfamily stderr}).
\end{DoxyItemize}

\begin{DoxyEnumerate}
\item {\bfseries{Traducción entre píxeles y el plano complejo\+:}}
\begin{DoxyItemize}

\begin{DoxyItemize}
\item Permite acercarse o alejarse del fractal ajustando las escalas, y desplazarse por diferentes partes del fractal modificando los límites.
\end{DoxyItemize}
\item {\bfseries{Eficiencia\+:}}
\begin{DoxyItemize}
\item Precalcular las escalas y los límites evita realizar estos cálculos para cada píxel, mejorando el rendimiento del renderizado.
\end{DoxyItemize}
\item {\bfseries{¿\+Por qué es crucial?}}
\begin{DoxyItemize}
\item Sin estas escalas y límites, sería imposible generar el fractal correctamente. Los fractales son gráficos basados en números complejos, y esta función conecta el mundo "{}físico"{} de los píxeles con el mundo "{}matemático"{} del plano complejo. 
\end{DoxyItemize}
