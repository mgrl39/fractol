{\footnotesize\ttfamily static void julia\+\_\+iterations (\begin{DoxyParamCaption}\item[{\mbox{\hyperlink{fractol_8h_a73bbfaa62c5d442e2541ea8e5626611d}{t\+\_\+render\+\_\+vars}} \texorpdfstring{$\ast$}{*}}]{vars,  }\item[{\mbox{\hyperlink{fractol_8h_a24e28e95867f9681b9d87781b1caa65b}{t\+\_\+data}} \texorpdfstring{$\ast$}{*}}]{data }\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [static]}}



Performs the iterations for a signle point in the Julia set. 

This function applies the Julia set formula iteratively to determine whether a given point escapes the threshold. The number of iterations taken before escape determines the point\textquotesingle{}s color.


\begin{DoxyItemize}
\item {\bfseries{Core Algorithm\+:}} The formula {\ttfamily z = z\texorpdfstring{$^\wedge$}{\string^}2 + c} is applied, where\+:
\begin{DoxyItemize}
\item {\ttfamily z} is a complex number, represented by real ({\ttfamily z\+\_\+re}) and imaginary ({\ttfamily z\+\_\+im}) parts.
\item {\ttfamily c} is a constant defined by the user (real and imaginary parts).
\end{DoxyItemize}
\item {\bfseries{Bounding Condition\+:}} The iteerations stop when\+:
\begin{DoxyItemize}
\item The sum of the squares of the real and imaginary parts exceeds 4.\+0.
\item The maximum number of iterations ({\ttfamily MAX\+\_\+\+ITERATIONS}) is reached.
\end{DoxyItemize}
\item {\bfseries{Optimization\+:}} Squared values ({\ttfamily z\+\_\+re\texorpdfstring{$^\wedge$}{\string^}2} and {\ttfamily z\+\_\+im\texorpdfstring{$^\wedge$}{\string^}2}) are cached to avoid redundant calculations.
\end{DoxyItemize}

Renders the Julia set fractal. 

Renders the Julia fractal.

This function handles the full rendering process for the Julia set by iterating through all rows of the screen, rendering each row sequentially.


\begin{DoxyItemize}

\begin{DoxyItemize}
\item Calculates the scaling and starting coordinates based on the zoom level and positional offsets provided by the user.
\end{DoxyItemize}
\item {\bfseries{Row-\/by-\/\+Row Rendering\+:}}
\begin{DoxyItemize}
\item For each row on the screen ({\ttfamily y} coordinate), the corresponding imaginary coordinate is computed.
\item The row is passed to {\ttfamily render\+\_\+julia\+\_\+row}, which handles the pixel-\/by-\/pixel rendering.
\end{DoxyItemize}
\item {\bfseries{Full Image Construction\+:}}
\begin{DoxyItemize}
\item The ffunction processes every row until the entire fractal is rendered.
\end{DoxyItemize}

Renders a single row of the Julia set. 

This function processes one row of the pixel in the Juliaa set by iterating through each pixel, applying the Juliaa set formula, and determining its color.


\begin{DoxyItemize}
\item {\bfseries{Coordinate Mapping\+:}}
\begin{DoxyItemize}
\item Each pixel is mapped to a complex number ({\ttfamily z}) based on its position and the scaling factors calculated from the zoom and offsets.
\end{DoxyItemize}
\item {\bfseries{Iteration and Coloring\+:}}
\begin{DoxyItemize}
\item The Julia set formula is applied iteratively for each pixel.
\item The number of iterations is used to calculate the pixel\textquotesingle{}s color.
\end{DoxyItemize}
\item {\bfseries{Row Processing\+:}} Each pixel in the row is processed sequentially, and the result is stored in the image buffer.
\end{DoxyItemize}
