\hypertarget{md__2home_2dev_2frfr_2julia__calcs_autotoc_md65}{}\doxysubsection{\texorpdfstring{¿\+Qué hace esta función?}{¿Qué hace esta función?}}\label{md__2home_2dev_2frfr_2julia__calcs_autotoc_md65}
La función {\ttfamily render\+\_\+julia\+\_\+row} renderiza una fila completa del fractal de Julia. Realiza las siguientes acciones para cada píxel en la fila\+:


\begin{DoxyEnumerate}
\item Calcula el número complejo inicial {\ttfamily z} para el píxel actual en función de las coordenadas del píxel y la escala.
\item Ejecuta el algoritmo de iteraciones de Julia para determinar el número de iteraciones necesarias para que el punto escape.
\item Usa el número de iteraciones para determinar el color del píxel mediante la función {\ttfamily calculate\+\_\+color}.
\item Guarda el color calculado en el buffer de píxeles.
\end{DoxyEnumerate}\hypertarget{md__2home_2dev_2frfr_2julia__calcs_autotoc_md66}{}\doxysubsection{\texorpdfstring{Parámetros}{Parámetros}}\label{md__2home_2dev_2frfr_2julia__calcs_autotoc_md66}

\begin{DoxyItemize}
\item {\ttfamily t\+\_\+render\+\_\+vars \texorpdfstring{$\ast$}{*}vars}\+: Puntero a la estructura que contiene variables utilizadas en el proceso de renderizado, como las escalas, las coordenadas iniciales, y el buffer de píxeles.
\item {\ttfamily t\+\_\+data \texorpdfstring{$\ast$}{*}data}\+: Puntero a la estructura que contiene los datos del fractal, como la constante del conjunto de Julia y el nivel de zoom.
\item {\ttfamily int y}\+: Índice de la fila (coordenada {\ttfamily y}) que se está renderizando.
\end{DoxyItemize}
