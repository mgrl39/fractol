\begin{DoxyItemize}
\item Avoid opening any new issues without having checked if your problem has already been reported. If there are no currently open issues that fit your problem\textquotesingle{}s description, feel free to \href{https://github.com/W2Codam/MLX42/issues/new/choose}{\texttt{ add it}}.
\item When writing an issue make sure to include a clear title and description as well as having filled out all the necessary information\+: System info, OS, OS-\/\+Version, ...
\item If possible add pictures of the issue.
\item Maybe fix it yourself \+:D ?
\end{DoxyItemize}\hypertarget{md_MLX42_2CONTRIBUTING_autotoc_md211}{}\doxysection{\texorpdfstring{Contributing}{Contributing}}\label{md_MLX42_2CONTRIBUTING_autotoc_md211}
Before thinking of adding a contribution, think. Is it necessary? Will this actually be a useful/required feature? Is your implementation good? Provide clear and documented explanation as to what was changed.
