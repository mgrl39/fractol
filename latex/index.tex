\chapter{Fractol\+: A Fractal Visualization Project}
\hypertarget{index}{}\label{index}\index{Fractol: A Fractal Visualization Project@{Fractol: A Fractal Visualization Project}}
\label{index_md_README}%
\Hypertarget{index_md_README}%
 Fractol is a fractal visualization tool written in C that leverages the MLX42 graphics library for rendering complex and stunning fractals. The project supports the generation of the Mandelbrot and Julia sets, with interactive controls for zooming, panning, and exploring these fascinating mathematical structures.\hypertarget{index_autotoc_md200}{}\doxysection{\texorpdfstring{Overview}{Overview}}\label{index_autotoc_md200}
Fractals are infinitely complex patterns that are self-\/similar across different scales. They are created by repeating a simple mathematical process over and over in an ongoing feedback loop. Fractol uses this principle to generate visually captivating fractal images.\hypertarget{index_autotoc_md201}{}\doxysubsection{\texorpdfstring{Supported Fractals}{Supported Fractals}}\label{index_autotoc_md201}

\begin{DoxyItemize}
\item Mandelbrot Set\+: A set of complex numbers that do not diverge when iteratively applied to the equation {\ttfamily z\+\_\+(n+1) = z\+\_\+n\texorpdfstring{$^\wedge$}{\string^}2 + c}, starting with {\ttfamily z\+\_\+0 = 0}.
\item Julia Set\+: A family of fractals defined for a fixed complex constant {\ttfamily c}, iterating over {\ttfamily z\+\_\+(n+1) = z\+\_\+n\texorpdfstring{$^\wedge$}{\string^}2 + c}.
\end{DoxyItemize}\hypertarget{index_autotoc_md202}{}\doxysection{\texorpdfstring{Mathematical Foundation}{Mathematical Foundation}}\label{index_autotoc_md202}
\hypertarget{index_autotoc_md203}{}\doxysubsection{\texorpdfstring{Complex Numbers}{Complex Numbers}}\label{index_autotoc_md203}
Fractals rely on complex numbers, which have two components\+:
\begin{DoxyItemize}
\item {\bfseries{Real part (Re)}}
\item {\bfseries{Imaginary part (Im)}}
\end{DoxyItemize}

Complex numbers can be represented as {\ttfamily z = a + bi}, where\+:
\begin{DoxyItemize}
\item {\ttfamily a} is the real component.
\item {\ttfamily b} is the imaginary component.
\item {\ttfamily i} is the square root of -\/1.
\end{DoxyItemize}\hypertarget{index_autotoc_md204}{}\doxysubsection{\texorpdfstring{Iteration and Divergence}{Iteration and Divergence}}\label{index_autotoc_md204}
The fundamental concept in fractal generation is iteration\+:
\begin{DoxyEnumerate}
\item Start with an initial complex number {\ttfamily z\+\_\+0}.
\item Iteratively apply the equation {\ttfamily z\+\_\+(n+1) = z\+\_\+n\texorpdfstring{$^\wedge$}{\string^}2 + c}.
\item Stop if the magnitude of {\ttfamily z}, given by {\ttfamily \texorpdfstring{$\vert$}{|}z\texorpdfstring{$\vert$}{|}\texorpdfstring{$^\wedge$}{\string^}2}, is greater than 4 (escape condition) or if the maximum number of iterations is reached.
\end{DoxyEnumerate}

The number of iterations before escape determines the color of a pixel, creating the fractal\textquotesingle{}s intricate patterns.\hypertarget{index_autotoc_md205}{}\doxysubsection{\texorpdfstring{Coordinate Mapping}{Coordinate Mapping}}\label{index_autotoc_md205}
The fractal exists in the complex plane, but pixels are rendered in a 2D screen coordinate system. Fractol maps each pixel to a corresponding complex number based on\+:
\begin{DoxyItemize}
\item The screen resolution.
\item The zoom level.
\item The viewport offset.
\end{DoxyItemize}\hypertarget{index_autotoc_md206}{}\doxysection{\texorpdfstring{Project Structure}{Project Structure}}\label{index_autotoc_md206}

\begin{DoxyEnumerate}
\item {\bfseries{Scaling and Limits}}\+:
\begin{DoxyItemize}
\item The {\ttfamily calculate\+\_\+scales\+\_\+and\+\_\+limits} function determines the scales and starting points for each axis of the fractal.
\item The scales adjust based on the zoom level to refine the detail as the user zooms in or out.
\end{DoxyItemize}
\item {\bfseries{Precomputed Coordinates}}\+:
\begin{DoxyItemize}
\item The {\ttfamily precompute\+\_\+coords} function calculates the complex coordinates for each pixel row in advance, improving efficiency.
\end{DoxyItemize}
\item {\bfseries{Rendering}}\+:
\begin{DoxyItemize}
\item For the Julia set ({\ttfamily render\+\_\+julia}) and Mandelbrot set ({\ttfamily render\+\_\+mandelbrot}), Fractol iterates through each pixel, computes whether it escapes, and assigns a color based on the number of iterations.
\end{DoxyItemize}
\end{DoxyEnumerate}\hypertarget{index_autotoc_md210}{}\doxysubsubsection{\texorpdfstring{Color Mapping}{Color Mapping}}\label{index_autotoc_md210}
The color of each pixel is determined by the number of iterations before escape. A smooth gradient effect is applied using\+:
\begin{DoxyItemize}
\item Normalized Iterations\+: Proportional mapping of the iteration count to a color gradient.
\item ARGB Encoding\+: Colors are represented in ARGB format for rendering.
\end{DoxyItemize}\hypertarget{index_autotoc_md211}{}\doxysubsubsection{\texorpdfstring{Interactive Controls}{Interactive Controls}}\label{index_autotoc_md211}

The Mandelbrot implementation includes early escape checks for points within known regions of the set, significantly speeding up rendering.\hypertarget{index_autotoc_md218}{}\doxysubsection{\texorpdfstring{Multi-\/\+Precision Calculations}{Multi-Precision Calculations}}\label{index_autotoc_md218}
