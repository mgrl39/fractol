\doxysubsection{Detailed Description}
Implementation of the Mandelbrot set rendering. 

This file contains all the functions necessary to compute and render the Mandelbrot set fractal. The Mandelbrot set is a visual representation off a mathematical formula applied to complex numbers. THe complexity and beauty of its patterns arise from how quickly or slowly each point "{}escapes"{} beyond a defined boundary.\hypertarget{mandelbrot_8c_autotoc_md172}{}\doxysubsubsubsection{\texorpdfstring{For Technical Users\+:}{For Technical Users:}}\label{mandelbrot_8c_autotoc_md172}

\begin{DoxyItemize}
\item {\bfseries{Core Algorithm\+:}} The Mandelbrot set uses the formula {\ttfamily z = z\texorpdfstring{$^\wedge$}{\string^}2 + c}, where\+:
\begin{DoxyItemize}
\item {\ttfamily z} starts at (0, 0) for every point.
\item {\ttfamily c} is the complex number corresponding to the pixel\textquotesingle{}s position on the screen.
\item Iterations continue until {\ttfamily \texorpdfstring{$\vert$}{|}z\texorpdfstring{$\vert$}{|}2 \texorpdfstring{$>$}{>} 4} (escape condition) or the maximum number of iterations is reached.
\end{DoxyItemize}
\item {\bfseries{Optimization\+:}}
\begin{DoxyItemize}
\item {\bfseries{Escape Checks\+:}} Early checks prevent unnecessary calculations for points.
\item {\bfseries{Precomputed Coordinates\+:}} Reduces redundant computations of pixel coordinates.
\item {\bfseries{Row-\/\+Based Rendering\+:}} Processes the fractal row by row for efficient memory and rendering operations.
\item {\bfseries{Color Mapping\+:}} The number of iteerations determines the color of each pixexl, creating vibrant and intricaate fractal patterns.
\end{DoxyItemize}
\end{DoxyItemize}\hypertarget{mandelbrot_8c_autotoc_md173}{}\doxysubsubsubsection{\texorpdfstring{For Non-\/\+Technical Users\+:}{For Non-Technical Users:}}\label{mandelbrot_8c_autotoc_md173}

\begin{DoxyItemize}
\item {\bfseries{What is the Mandelbrot Set?}} The Mandelbrot set is a mathematical design created by repeatedly applying a simple formula to point on a grid. Points that "{}escape"{} quickly create bright colors, while points that stay "{}trapped"{} generate the darker areas of the fractal. 
\end{DoxyItemize}
