\doxysubsection{Detailed Description}
Entry point for the Fractol application. 

This file contains the main function and orchestrates the entire fractal rendering process. It handles\+:
\begin{DoxyItemize}
\item Command-\/line argument validation to ensure correct input.
\item Initialization of the fractal type and parameters (Julia or Mandelbrot)
\item Setuup of the rendering environment using the MLX42 graphics liibrary, including the creation of the window and image bufffer.
\item Fractal rendering based on the user-\/specified parameters.
\item Configuration of interactivee event hooks for keyboard and scroll inputs.
\item Continuous updates through the main event loop.
\end{DoxyItemize}

The program terminates gracefully on completion or reports error for invalid inputs.

Validates the command-\/line arguments for fractal rendering. 

This function checks that the user has specified a valid fractal type and the correct parameters. The supported fractals and their requirements are\+:
\begin{DoxyItemize}
\item {\ttfamily mandelbrot}\+: No additional arguments.
\item {\ttfamily julia}\+: Requires exactly two valid numbers representing the real and imaginary part of the parameter.
\end{DoxyItemize}

If the arguments are invalid, the function calls {\ttfamily \doxylink{main_8c_a2b8d2884ae79f1a4148a72db584e88f9}{exit\+\_\+with\+\_\+error()}} to display an appropiate error message and terminate the program.
